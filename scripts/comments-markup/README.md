# Разметка заметок «Словаря»

Скрипты, которыми при переносе «Словаря заморских слов» в Directus (2026-09) приводились к единому виду тексты
заметок (`comments.body`). Годятся и для новых заметок.

- `normalize.py` — точка входа: `python3 normalize.py заметка.html > готово.html`; замечания, которые нужно
  решить вручную (слова капсом, сомнительные `/`, классы `editor-aside`), печатаются в stderr.
  Ключ `--source` — только для текста со старого сайта (`<em>` → `<i>`, `<b>` → `<em>`); повторно не применять.
- `slovar_markup.py` — правила (`normalize_body`): латинские двойники букв, пробелы, ссылки на зеркала старого
  сайта → внутренние, тире и диапазоны, `//` в строках стиха, `<dfn>` у объясняемого слова, вынос `<blockquote>`
  из абзаца. Описание правил — в начале файла и в `docs/directus.md`.
- `slovar_quotes.py` — кавычки по глубине вложенности: «ёлочки» → „лапки“ → ‘одиночные’.

Повторный прогон уже приведённого текста ничего не меняет (кроме режима `--source`). В базу скрипты не пишут:
результат вставляется в поле `body` в Directus (интерфейс поля — код, не визуальный редактор).
