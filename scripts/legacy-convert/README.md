# Конвертер legacy-страниц (KOI8-R, HTML 3.2/4) → Hugo `praises-article`

Написан при переносе `fans/` (2026-09-26): 44 страницы за один заход. Годится для `Parodies/`, `SCH2/` и прочих
статичных разделов старого сайта. Каталог `draft/` создаётся при запуске, в git не нужен.

- `fconv.py` — конвертер одного файла: разбор html5lib, вычистка навигации, unwrap таблиц/`font`, теги в нижнем
  регистре, типографика по правилам «Отзывов» (` - ` → `&nbsp;&mdash;`, `"…"` → «…» с учётом вложенности,
  латинские двойники букв в русских словах → кириллица), `<br>`-стихи → `<p class="verse">`, `<pre>` без общего отступа.
- `meta.py` — таблица по страницам: заголовок, автор, `subtitle`, куда ведёт «назад» (`back`), `lastmod`, сколько блоков
  сверху/снизу выбросить (`drop_first/drop_last`), точечные `replace` (строки или `re:`-регэкспы), `src_replace/src_fn`
  (правка исходника до разбора), `fontmap` (цвет `<font>` → класс `spoiler|rhyme|datum`), `keep_table`, `split_br2`,
  `no_typo` (не трогать пунктуацию), `raw_quotes` (не менять кавычки в блоках с непарными).
- `build.py [имя …]` — собирает `draft/<имя>.md` (без аргументов — весь список `NAMES`). Файлы из `manual/<имя>.md`
  копируются как есть (для страниц, где проще написать руками). Ссылки на песни `texts/ГГГГ/id.html`
  сверяются с `content/texts/`: год чинится по id, известные переименования — в `MANUAL`, остальные остаются без ссылки
  (текст остаётся), список выводится в конце.

Порядок работы: прогнать `build.py`, просмотреть черновики (предупреждения о непарных кавычках, «`replace not found`»),
дописать `meta.py`, скопировать `draft/*.md` в `content/…`, положить картинки в `static/…`, собрать сайт
(`hugo --destination /tmp/…`), прогнать `scripts/check-links.py` и `scripts/check-separation.py`.
Счётчик слов «исходник ↔ страница» полезен, но не ловит потерянный последний блок.

**Другие разделы:** `SECTION=Parodies python3 build.py` (или `SECTION=SCH2`) читает `www/<SECTION>/`, берёт метаданные из `meta_<SECTION>.py`, пишет в
`draft/<SECTION>/`. Хабы `index.html` получают имя `<раздел>-index.md`. Для нового раздела: завести `meta_<Раздел>.py`, добавить «назад» в `DEFAULT_BACK`.
Кавычки: «…» → „…“ → ‘…’ по глубине вложенности.
